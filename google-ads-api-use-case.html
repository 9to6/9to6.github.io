Google Ads API 사용 목적

UniqBuild의 Google Ads 및 Google Ads API 사용 방식 안내

UniqBuild 소개

UniqBuild는 모바일 애플리케이션을 개발하고 운영하는 회사입니다. 대한민국 서울에 위치하며, 자사 개발자 계정으로 App Store와 Google Play에 iOS 및 Android 앱을 출시하고 있습니다.

Google Ads 사용 목적

UniqBuild는 자사 모바일 앱의 사용자 확보를 위해 Google Ads를 사용하며, 주로 Google Ads 앱 설치 캠페인(App Install Campaign)을 운영합니다. Google Ads API 사용과 관련된 모든 Google Ads 계정은 UniqBuild가 소유하고 직접 운영하는 계정입니다.

Google Ads API 사용 용도

Google Ads API는 자사 Google Ads 계정 내에서 두 가지 용도로 사용됩니다: (1) 캠페인 관리 — 자사 앱 설치 캠페인을 프로그래밍 방식으로 생성·수정·일시중지·재개하고 예산과 입찰가를 조정합니다. (2) 리포팅 및 분석 — 캠페인 성과 데이터(비용, 노출, 클릭, 앱 설치 전환 지표 등)를 조회합니다.

조회된 데이터는 UniqBuild의 내부 대시보드 및 리포트에 사용되어 자사 앱들의 캠페인 성과를 모니터링하고 효율을 비교하며, 위의 관리 작업에 활용됩니다.

API로 사용하는 대표 작업 및 필드:

  • 캠페인 관리: 캠페인 생성·수정·일시중지(CampaignService), 예산 조정(CampaignBudgetService), 입찰가·상태 변경
  • campaign.name, campaign.status — 캠페인 식별 및 상태
  • metrics.cost_micros — 광고 비용
  • metrics.impressions, metrics.clicks — 노출 및 클릭
  • metrics.conversions — 앱 설치 전환
  • 내부에서 계산하는 파생 지표: CPI(설치당 비용), CPC, 설치 전환율, ROAS

데이터 흐름: Google Ads API → UniqBuild 내부 데이터 저장소 → UniqBuild 직원만 열람하는 내부 대시보드. 어떠한 데이터도 외부에 공개하거나 공유하지 않습니다.

사용 범위 제한

UniqBuild는 광고 대행 서비스를 제공하지 않으며, 제3자의 Google Ads 계정을 관리하거나 외부 고객을 대신해 Google Ads 데이터를 처리하지 않습니다. Google Ads API는 오로지 자사 앱 홍보 캠페인의 성과 데이터를 조회하고 분석하기 위한 용도로만 사용됩니다.
