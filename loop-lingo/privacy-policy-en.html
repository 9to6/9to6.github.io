Privacy Policy

Last Updated: May 22, 2026

Summary: Loop Lingo does not transmit any data to external servers. All data is stored exclusively on your device. We do not use advertising, analytics tools, or any third-party tracking services.

1. Introduction

Teukgeon Kwon ("Developer", "we", "us", "our") provides Loop Lingo ("Extension", "Service") as a Chrome browser extension. This service is provided "as is."

This Privacy Policy explains how data is handled when you use Loop Lingo. By installing and using this extension, you agree to this policy.

Extension Information:

  • Name: Loop Lingo
  • Type: YouTube language learning Chrome extension
  • Platform: Google Chrome (Desktop)
  • Developer: Teukgeon Kwon (UniqBuild)

2. Data Handling

2.1 Information We Do NOT Collect

Loop Lingo does not collect or transmit the following information:

  • Personal identifiers such as name, email address, or phone number
  • Location data
  • Advertising identifiers (IDFA, AAID, etc.)
  • Browser history
  • YouTube watch history or account information
  • Device information or IP address

We do not use any analytics tools, advertising networks, or third-party tracking services.

2.2 Data Stored Locally on Your Device

The extension stores the following data exclusively in chrome.storage.local on your device. This data is never transmitted externally:

  • Preferences: Learning language, native language, UI language, selected learning flow, panel visibility state, panel opacity
  • Custom learning flows: User-created step configurations for the learning workflow
  • Session history: Local learning history including YouTube video IDs, segment timestamps, and practice counts

This data exists only on the device where the extension is installed and is never stored on our servers or any external service.

2.3 Segment Sharing Feature

When using the segment sharing feature, study segment information (start/end timestamps and a learning flow snapshot) is Base64-encoded and appended as a query parameter to a YouTube URL. This data does not pass through any server — it is shared entirely through the generated URL.

3. Permission Usage

Loop Lingo uses the following Chrome extension permissions:

3.1 storage

Used to persist preferences, custom learning flows, and session history in chrome.storage.local. All data remains on your device and is never transmitted externally.

3.2 activeTab

Used by the toolbar popup to verify whether the currently active tab is a YouTube watch page. This permission is not used to read or modify tab content.

3.3 Host Permission (https://www.youtube.com/*)

Required to inject the learning panel content script into YouTube watch pages. The content script controls the YouTube video player (play, pause, seek) and interacts with the captions UI to implement segment loop learning. This permission applies exclusively to youtube.com and does not access any other websites.

4. Data Security

All data in Loop Lingo is stored locally on your device and managed through Chrome's storage.local API. Since there is no external server transmission, there is no network transmission security risk.

Access to stored data requires the same Chrome profile with the Loop Lingo extension installed.

5. Data Retention and Deletion

You can delete your data in the following ways:

  • Uninstall the extension: Removing Loop Lingo from Chrome deletes all data stored in chrome.storage.local.
  • Clear Chrome data: You can clear browser data including extension data through Chrome settings.

Since no user data exists on our servers, no server-side deletion process is required.

6. Children's Privacy

This service is not directed at children under the age of 13 (or the minimum age defined by local law). While the extension does not collect any personal information, we recommend that parents or guardians monitor their child's use of the extension.
