개인정보처리방침

최종 업데이트: 2026년 5월 22일

요약: Loop Lingo는 외부 서버로 어떠한 데이터도 전송하지 않습니다. 모든 데이터는 사용자의 기기에만 저장됩니다. 광고, 분석 도구, 제3자 추적 서비스를 사용하지 않습니다.

1. 서론

Teukgeon Kwon("개발자", "저희", "당사")은 Loop Lingo("확장 프로그램", "서비스")를 크롬 브라우저 확장 프로그램으로 제공합니다. 본 서비스는 "있는 그대로" 제공됩니다.

이 개인정보처리방침은 Loop Lingo 사용 시 데이터가 어떻게 처리되는지 설명합니다. 본 확장 프로그램을 설치하고 사용함으로써 귀하는 본 방침에 동의하게 됩니다.

확장 프로그램 정보:

  • 이름: Loop Lingo
  • 유형: YouTube 언어 학습 크롬 확장 프로그램
  • 플랫폼: Google Chrome (데스크톱)
  • 개발자: Teukgeon Kwon (UniqBuild)

2. 데이터 처리 방식

2.1 수집하지 않는 정보

Loop Lingo는 다음 정보를 수집하거나 전송하지 않습니다:

  • 이름, 이메일, 전화번호 등 개인 식별 정보
  • 위치 정보
  • 광고 식별자 (IDFA, AAID 등)
  • 브라우저 방문 기록
  • YouTube 시청 기록 또는 계정 정보
  • 기기 정보, IP 주소

당사는 어떠한 분석 도구, 광고 네트워크, 제3자 추적 서비스도 사용하지 않습니다.

2.2 기기에만 저장되는 정보

확장 프로그램은 다음 데이터를 사용자의 기기 내 chrome.storage.local에만 저장합니다. 이 데이터는 외부로 전송되지 않습니다:

  • 환경설정: 학습 언어, 모국어, UI 언어, 선택한 학습 플로우, 패널 표시 설정, 패널 투명도
  • 사용자 정의 학습 플로우: 사용자가 직접 만든 학습 단계 설정
  • 세션 기록: 학습한 YouTube 동영상 ID, 구간 타임스탬프, 연습 횟수 등 로컬 학습 이력

이 데이터는 확장 프로그램 설치 기기에만 존재하며, 당사 서버 또는 어떤 외부 서비스에도 저장되지 않습니다.

2.3 구간 공유 기능

구간 공유 기능을 사용하면 학습 구간 정보(시작/종료 시간, 학습 플로우 스냅샷)가 YouTube URL의 쿼리 파라미터에 Base64로 인코딩되어 포함됩니다. 이 데이터는 서버를 거치지 않으며, 생성된 URL을 공유하는 방식으로만 전달됩니다.

3. 권한 사용 목적

Loop Lingo는 다음 크롬 확장 프로그램 권한을 사용합니다:

3.1 storage 권한

환경설정, 사용자 정의 학습 플로우, 세션 기록을 chrome.storage.local에 저장하기 위해 사용합니다. 모든 데이터는 기기에만 보관되며 외부로 전송되지 않습니다.

3.2 activeTab 권한

팝업에서 현재 활성 탭이 YouTube 시청 페이지인지 확인하기 위해 사용합니다. 탭의 콘텐츠를 읽거나 수정하는 데 사용되지 않습니다.

3.3 호스트 권한 (https://www.youtube.com/*)

YouTube 시청 페이지에 학습 패널 콘텐츠 스크립트를 삽입하기 위해 사용합니다. 콘텐츠 스크립트는 YouTube 동영상 플레이어의 재생/일시정지/탐색을 제어하고, 자막 UI를 조작하여 구간 반복 학습을 구현합니다. 이 권한은 youtube.com에만 적용되며 다른 웹사이트에는 접근하지 않습니다.

4. 데이터 보안

Loop Lingo의 모든 데이터는 사용자의 기기에만 저장되며 Chrome의 storage.local API를 통해 관리됩니다. 외부 서버 전송이 없으므로 네트워크 전송 보안 위험이 없습니다.

저장된 데이터에 접근하려면 동일한 Chrome 프로필과 Loop Lingo 확장 프로그램이 필요합니다.

5. 데이터 보관 및 삭제

데이터는 다음 방법으로 삭제할 수 있습니다:

  • 확장 프로그램 제거: Chrome에서 Loop Lingo를 제거하면 chrome.storage.local에 저장된 모든 데이터가 삭제됩니다.
  • Chrome 데이터 삭제: Chrome 설정에서 확장 프로그램 데이터를 포함한 브라우저 데이터를 삭제할 수 있습니다.

당사 서버에는 사용자 데이터가 존재하지 않으므로 별도의 서버 측 삭제 절차가 필요하지 않습니다.

6. 아동의 개인정보 보호

본 서비스는 만 13세 (또는 해당 지역 법률에서 정한 최소 연령) 미만의 아동을 대상으로 하지 않습니다. 확장 프로그램 자체적으로 어떠한 개인정보도 수집하지 않으나, 부모 또는 보호자가 아동의 확장 프로그램 사용을 모니터링할 것을 권장합니다.

7. 사용자의 권리

Loop Lingo는 외부 서버에 사용자 데이터를 저장하지 않으므로, 데이터 접근·수정·삭제 요청은 사용자가 직접 Chrome 설정을 통해 처리할 수 있습니다.

방침 관련 문의는 아래 연락처로 보내주세요.

7.1 한국 거주자 (개인정보보호법)

한국 개인정보보호법에 따라 한국 거주자는 다음 권리를 가집니다:

  • 개인정보 열람 청구
  • 개인정보 정정 및 삭제 요구
  • 개인정보 처리 정지 요구

Loop Lingo는 외부 서버에 개인정보를 보관하지 않으므로, 확장 프로그램을 제거하면 모든 로컬 데이터가 삭제됩니다.

7.2 유럽연합 거주자 (GDPR)

Loop Lingo는 개인 데이터를 처리하거나 전송하지 않으므로, 데이터 처리자 관점에서 GDPR의 적용 범위가 제한적입니다. 문의 사항이 있으시면 아래 연락처로 연락해 주세요.

7.3 캘리포니아 거주자 (CCPA)

Loop Lingo는 개인정보를 수집, 판매하거나 제3자와 공유하지 않습니다.

8. 제3자 서비스

Loop Lingo는 광고, 분석, 추적 목적의 제3자 서비스를 포함하지 않습니다.

확장 프로그램이 youtube.com에서 실행될 때, YouTube 자체의 서비스(동영상 플레이어, 자막 UI)를 제어하지만 YouTube의 데이터를 수집하거나 저장하지는 않습니다. YouTube의 개인정보처리방침은 Google의 서비스에 적용됩니다.

9. 개인정보처리방침 변경

당사는 개인정보처리방침을 수시로 업데이트할 수 있습니다. 변경 사항은 본 페이지에 게시되며, 페이지 상단의 "최종 업데이트" 날짜가 갱신됩니다.

중요한 변경이 있는 경우 Chrome Web Store 확장 프로그램 업데이트 노트를 통해 안내할 수 있습니다.
