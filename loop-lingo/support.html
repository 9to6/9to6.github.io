데이터 삭제

Loop Lingo는 서버에 데이터를 저장하지 않습니다. 모든 데이터는 사용자의 기기에만 저장됩니다.

데이터 삭제 방법

Loop Lingo의 모든 데이터를 삭제하려면 다음 단계를 따르세요:

  1. Chrome 주소창에 chrome://extensions 입력
  2. Loop Lingo 확장 프로그램 찾기
  3. "제거" 버튼 클릭
  4. 확인 메시지에서 "제거" 클릭

확장 프로그램을 제거하면 chrome.storage.local에 저장된 모든 데이터(환경설정, 학습 플로우, 세션 기록 등)가 즉시 삭제됩니다.

삭제되는 데이터

확장 프로그램 제거 시 다음 데이터가 영구적으로 삭제됩니다:

  • 학습 언어, 모국어, UI 언어 등 환경설정
  • 사용자 정의 학습 플로우
  • 세션 기록 (학습한 동영상 ID, 타임스탬프, 연습 횟수)
  • 패널 표시 설정, 투명도 등 기타 설정

참고사항

당사 서버에는 사용자 데이터가 존재하지 않으므로 별도의 서버 측 삭제 절차가 필요하지 않습니다. 확장 프로그램을 제거하면 모든 데이터가 즉시 삭제됩니다.

복구가 불가능하니 신중하게 진행해 주세요.
