Data Deletion

Loop Lingo does not store any data on servers. All data is stored only on your device.

How to Delete Your Data

To delete all Loop Lingo data, follow these steps:

  1. Type chrome://extensions in the Chrome address bar
  2. Find the Loop Lingo extension
  3. Click the "Remove" button
  4. Confirm by clicking "Remove" in the dialog

Once the extension is removed, all data stored in chrome.storage.local (settings, learning flows, session history, etc.) will be immediately deleted.

What Data Will Be Deleted

Upon extension removal, the following data will be permanently deleted:

  • Settings (learning language, native language, UI language)
  • Custom learning flows
  • Session history (video IDs, timestamps, practice counts)
  • Panel display settings, transparency, and other preferences

Note

Since no user data exists on our servers, no separate server-side deletion process is required. Removing the extension immediately deletes all data.

This action cannot be undone, so please proceed with caution.
